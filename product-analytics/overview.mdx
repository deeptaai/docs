Product Analytics gives you four dashboards covering different aspects of product performance. Each one is pre-built: you define which events represent your product's key actions, and the dashboards populate from there.

## What each dashboard is for

| Dashboard | Purpose | Answers |
| :-- | :-- | :-- |
| **Product Overview** | Overall product health | How is my product doing overall? |
| **Onboarding** | New user journey | Are new users able to get started easily? |
| **Feature Engagement** | Feature usage | Which features are users actually using? |
| **Retention** | User return behavior | Are users coming back after using the product? |

---

## Controls shared across the dashboards

All four dashboards share the same set of global controls.

### Filters

Filter the entire dashboard by user properties or event properties. All metrics and charts update dynamically when filters are applied.

### Segments

Segments let you analyze specific groups of users — new users, paying users, users from a particular campaign. You can create your own segments.

### Data freshness indicator

Displays the time of the last data update, so you know how recent the numbers are.

```text
Data from 3 min ago
```

### Date range

| Option |
| :-- |
| Today |
| Yesterday |
| Last 7 days |
| Last 30 days |
| Custom date range |

### Time granularity

Granularity defines how data points appear in the chart. Product Overview, Onboarding, and Retention support Hourly, Daily, Weekly, Monthly, and Quarterly. Feature Engagement supports Daily, Weekly, Monthly, and Quarterly.

---

## Configurations

Each dashboard is driven by events you choose. Click **Configurations** to open the Product Analytics Configuration page, which has a left navigation panel containing:

- Product Overview *(selected by default)*
- Onboarding Analysis
- Feature Engagement
- Retention Analysis

Configuration changes take effect on save and impact KPI metrics, charts, retention calculations, and breakdown tables.

---

## Data refresh

Dashboards refresh automatically when any of the following change:

- Filters
- Segments
- Date range
- Breakdown dimension

---

## Empty state

When no data matches the current setup, the dashboard shows:

```text
Oops! No data matches your current chart setup.
```

This happens when filters exclude all data, when the events are not yet being tracked, or when the date range contains no events.
