## Pinning does not change permissions

Pinning places a chart somewhere. It does not grant anyone access to it.

A chart's permissions travel with the chart, not with the dashboard it sits on. Someone who can open a dashboard may still be unable to open a chart pinned to it, and Klaritics shows a permission-restricted state rather than exposing the data.

---

## Pinning to Overview

Overview behaves differently from a dashboard, because it is a common project-level page.

A chart pinned to Overview has its **card** visible to all project users. What happens when they interact with it still depends on their chart permission.

| Chart permission | Sees the card | Can open | Can edit |
| :-- | :--: | :--: | :--: |
| Full Access | ✓ | ✓ | ✓ |
| Editor | ✓ | ✓ | ✓ |
| Viewer | ✓ | ✓ | ✗ |
| No Access | ✓ | ✗ | ✗ |

<Warning>
  Overview visibility is project-level. A user with no access to the chart still sees the card, but cannot open or edit it, and the chart data is never exposed.
</Warning>
