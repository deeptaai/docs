The Klaritics Web SDK sends analytics events from the browser to your self-hosted Klaritics instance. Install it from npm for bundler-based projects, or load it with a script tag.

**Package:** `@deeptaai/klaritics-web-sdk`

## Requirements

You need a **Project ID** and a **Server host** from the Klaritics dashboard. Your project ID is on the **Getting Started** page.

## Installation

<Tabs>
  <Tab title="npm">
    ```bash
    npm install --save @deeptaai/klaritics-web-sdk
    ```

    ```javascript
    import Klaritics from "@deeptaai/klaritics-web-sdk";
    ```
  </Tab>
  <Tab title="Script tag">
    The `defer` attribute loads the SDK after the page content.

    ```html
    <script type="text/javascript" defer
      src="https://unpkg.com/@deeptaai/klaritics-web-sdk@latest">
    </script>
    ```
  </Tab>
</Tabs>

## Initialize the SDK

Call `Klaritics.init` once, before any other Klaritics call:

```javascript
Klaritics.init("YOUR_PROJECT_ID", {
  server_host: "https://YOUR_SERVER_HOST"
});
```

The first argument is your `project_id`.

### Options

| Option | Type | Description |
| --- | --- | --- |
| `server_host` | `string` | **Required.** URL of your Klaritics instance. |
| `honorDNT` | `boolean` | Honor the browser's Do Not Track setting. |
| `idle_time_out` | `number` | Milliseconds of inactivity before a session ends. |
| `version` | `string` | Application version to attach to events. |

## API reference

| Method | Usage | Description |
| --- | --- | --- |
| `init` | `init(projectId, options)` | Initialize the SDK. |
| `logEvent` | `logEvent(eventName, properties, beforeRefresh?)` | Log an analytics event. Pass `true` as the third argument to send it before a page refresh. |
| `setUserId` | `setUserId(userId)` | Identify the current user. |
| `setUserProperties` | `setUserProperties(properties)` | Attach user properties. |
| `setSessionProperties` | `setSessionProperties(properties)` | Attach properties to the current session. |
| `getDeviceId` | `getDeviceId()` | Return the SDK-generated device ID. |
| `startNewSession` | `startNewSession()` | Start a new session manually. |
| `endSession` | `endSession()` | End the current session manually. |

## Common recipes

### Log events

<CodeGroup>

```javascript Standard event
Klaritics.logEvent("product_clicked", {
  product_id: "sku-123",
  category: "electronics"
});
```

```javascript Before refresh
// Third argument `true` sends the event before a page refresh
Klaritics.logEvent("checkout_started", { cart_value: 99.99 }, true);
```

</CodeGroup>

### Identify a user and set properties

```javascript
Klaritics.setUserId("user_123");

Klaritics.setUserProperties({ plan: "pro", signup_date: "2024-01-15" });

Klaritics.setSessionProperties({ campaign: "summer_sale" });
```

### Get the device ID and control sessions

```javascript
const deviceId = Klaritics.getDeviceId();

Klaritics.startNewSession();
Klaritics.endSession();
```

## Single-page applications

Use your existing route-change handler to log events on navigation. URL-based page tracking is configured from the Klaritics dashboard and needs no extra SDK setup.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Events lost when the page reloads | Pass `true` as the third argument to `logEvent` for events fired just before a refresh. |
| Nothing is sent | Check that `init` runs before any other call, with a valid `server_host`. |
