The Klaritics Flutter SDK is a Dart wrapper around the native Klaritics Android and iOS SDKs. A single call from Dart initializes both platforms, so you add no setup code to your `Activity`, `Application`, or `AppDelegate`.

**Package:** `klaritics_flutter` · **Version:** 1.0.0

## Requirements

| Requirement | Value |
| --- | --- |
| Flutter | `>= 3.0.1` |
| iOS dependency manager | Swift Package Manager (Flutter's SwiftPM support enabled) |

You need a **Project ID** and a **Host URL** from the Klaritics dashboard. Your project ID is on the **Getting Started** page.

## Add the dependency

```yaml pubspec.yaml
dependencies:
  klaritics_flutter: ^1.0.0
```

```dart
import 'package:klaritics_flutter/klaritics_flutter.dart';
```

## Initialize the SDK

Initialize **once**, from `main()` before `runApp`, and `await` the call before logging any events:

```dart main.dart
Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  final config = KlariticsConfig('YOUR_PROJECT_ID');
  config.host = 'https://YOUR_SERVER_HOST';
  await KlariticsFlutter.setup(config);

  runApp(const MyApp());
}
```

### `KlariticsConfig`

| Property | Type | Description |
| --- | --- | --- |
| *(constructor argument)* | `String` | **Required.** Your `project_id` from the Klaritics dashboard. |
| `host` | `String` | **Required.** Server URL to send data to. |

<Tip>
  Because initialization happens from Dart, don't call the native `Klaritics.setup(...)` in your Android `Activity` or `Application`, or in your iOS `AppDelegate`.
</Tip>

## Android setup

<Steps>
  <Step title="Add the Klaritics Maven repository">
    Add it to the `repositories` block in `android/build.gradle` (or `settings.gradle`):

    ```groovy android/build.gradle
    maven {
        url "https://asia-south1-maven.pkg.dev/org-infra-471907/klaritics-android-sdk"
    }
    ```
  </Step>
  <Step title="Add the native SDK dependency">
    ```groovy app/build.gradle
    dependencies {
        implementation "com.deeptaai.klaritics:klaritics-android-sdk:1.0.0"
    }
    ```
  </Step>
  <Step title="Configure ProGuard">
    If you use ProGuard, add to `proguard-rules.pro`:

    ```proguard proguard-rules.pro
    -keep class com.deeptaai.klaritics.** { *; }
    -dontwarn com.deeptaai.klaritics.**
    ```
  </Step>
</Steps>

## iOS setup

The plugin declares the native Klaritics iOS SDK in its `Package.swift`. With Flutter's Swift Package Manager support enabled, it's added to your iOS app automatically. No `AppDelegate` changes are required.

## API reference

All methods are called on `KlariticsFlutter`.

| Method | Usage | Description |
| --- | --- | --- |
| `setup` | `await setup(config)` | Initialize both platforms. Call once, before anything else. |
| `logAppEvent` | `logAppEvent(eventName, attributes: {...})` | Log an analytics event. |
| `logClientEvent` | `logClientEvent(eventName, attributes: {...})` | Log an event that stays on the device. |
| `setUserIdentifier` | `setUserIdentifier(userId)` | Attach your own identifier to the current user. |
| `setUserAttributes` | `setUserAttributes({...})` | Set user-level attributes. |
| `setSessionAttributes` | `setSessionAttributes({...})` | Set attributes for the current session. |

## Common recipes

### Log events

```dart
KlariticsFlutter.logAppEvent("login", attributes: {
  "type": "google",
  "language": "en",
});

// Client events stay on the device — use them for local logic such as nudges
KlariticsFlutter.logClientEvent("soft_back_pressed", attributes: {
  "screen_name": "payment",
});
```

### Identify a user and set attributes

The SDK captures a device ID automatically. Add your own identifier when you want to follow a specific user's journey:

```dart
KlariticsFlutter.setUserIdentifier("user_123");

KlariticsFlutter.setUserAttributes({
  'age': 27,
  'plan': 'pro',
});

// A session runs from opening the app to closing it
KlariticsFlutter.setSessionAttributes({
  "network": "4G",
  "location": "Hyderabad",
});
```

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Events logged before setup are missing | `await KlariticsFlutter.setup(config)` in `main()` before `runApp`. |
| Android build can't resolve `klaritics-android-sdk` | Add the Maven repository. See [Android setup](#android-setup). |
| iOS doesn't pick up the native SDK | Enable Flutter's Swift Package Manager support. |
