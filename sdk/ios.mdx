The Klaritics iOS SDK collects analytics from iOS apps and sends them to your self-hosted Klaritics instance. Add it with Swift Package Manager, then initialize it once from your app delegate.

**Package:** `github.com/deeptaai/klaritics-ios-sdk` · **Version:** 1.0.0

## Requirements

| Requirement | Value |
| --- | --- |
| Package manager | Swift Package Manager |
| Languages | Swift, Objective-C |

You need a **Project ID** and a **Host URL** from the Klaritics dashboard. Your project ID is on the **Getting Started** page.

## Add the package

<Steps>
  <Step title="Open Add Package Dependencies">
    In Xcode, choose **File → Add Package Dependencies**.
  </Step>
  <Step title="Add the Klaritics repository">
    Paste the repository URL:

    ```text
    github.com/deeptaai/klaritics-ios-sdk
    ```
  </Step>
  <Step title="Add the library to your target">
    In **Choose Package Products**, select the **Klaritics** library, choose your app target under **Add to Target**, and click **Add Package**.
  </Step>
</Steps>

Xcode resolves and downloads the dependency in the background.

## Initialize the SDK

Import Klaritics and call `Klaritics.setup(config)` once, in `application(_:didFinishLaunchingWithOptions:)`, before any other Klaritics call.

```swift AppDelegate.swift
import Klaritics

@UIApplicationMain
class AppDelegate: NSObject {

    func application(_ application: UIApplication,
                     didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {

        let config = KlariticsConfig(appId: "YOUR_PROJECT_ID", host: "https://YOUR_SERVER_HOST")
        Klaritics.setup(config)

        return true
    }
}
```

### `KlariticsConfig`

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `appId` | `String` | — (required) | Your `project_id` from the Klaritics dashboard (Getting Started page). |
| `host` | `String` | — (required) | Server URL to send data to. |

<Warning>
  The SDK does not initialize until **both** `appId` and `host` are provided.
</Warning>

## API reference

All methods are called on `Klaritics`. Attributes are `[String: Any]` dictionaries.

| Method | Swift | Objective-C |
| --- | --- | --- |
| `setup` | `setup(_ config: KlariticsConfig)` | `setup:` |
| `logAppEvent` | `logAppEvent(withName:info:)` | `logAppEventForEvent:withInfo:` |
| `logAggregateEvent` | `logAggregateEvent(withName:info:)` | `logAggregateEventForEvent:withInfo:` |
| `logClientEvent` | `logClientEvent(withName:info:)` | `logClientEventForEvent:withInfo:` |
| `setUserIdentifier` | `setUserIdentifier(_:)` | `setUserIdentifier:` |
| `setUserCustomInfo` | `setUserCustomInfo(_:)` | `setUserCustomInfo:` |
| `setSessionCustomInfo` | `setSessionCustomInfo(_:)` | `setSessionCustomInfo:` |
| `trackScreen` | `trackScreen(_:)` | `trackScreen:` |
| `logRedirectionEvent` | `logRedirectionEvent(_:)` | `logRedirectionEvent:` |
| `reportCustomError` | `reportCustomError(key:errorInfo:)` | `reportCustomErrorWithKey:errorInfo:` |
| `getDeviceId` | `getDeviceId() -> String?` | `getDeviceId` |

<Note>
  iOS SDK v1.0.0 does not expose `logMetaEvent`, `resetUserCustomInfo`, `resetSessionCustomInfo`, `setCurrentScreenName`, `setPushRegistrationToken`, `setDynamicConfig`, `flushEventsIfAny`, or `optOut`. These are available on Android.
</Note>

## Common recipes

### Log events

<CodeGroup>

```swift Swift
Klaritics.logAppEvent(withName: "button_clicked", info: ["button_label": "Submit"])

// Counted and batched server-side
Klaritics.logAggregateEvent(withName: "purchase_completed", info: ["value": 1299])

// Stays on the device
Klaritics.logClientEvent(withName: "soft_back_pressed", info: ["screen": "home"])
```

```objc Objective-C
[Klaritics logAppEventForEvent:@"button_clicked" withInfo:@{ @"button_label": @"Submit" }];

[Klaritics logAggregateEventForEvent:@"purchase_completed" withInfo:@{ @"value": @1299 }];

[Klaritics logClientEventForEvent:@"soft_back_pressed" withInfo:@{ @"screen": @"home" }];
```

</CodeGroup>

### Identify a user and set properties

```swift
Klaritics.setUserIdentifier("user_123")

Klaritics.setUserCustomInfo(["email": "user@example.com", "plan": "pro"])

// Session-scoped properties
Klaritics.setSessionCustomInfo(["network": "4G"])

let deviceId = Klaritics.getDeviceId()
```

### Screens, redirections, and errors

```swift
Klaritics.trackScreen("home")

Klaritics.logRedirectionEvent("https://example.com/offer")

Klaritics.reportCustomError(key: "payment_failed", errorInfo: ["code": "E42"])
```

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Nothing is sent | Check that both `appId` and `host` are set in `KlariticsConfig`. The SDK doesn't initialize without both. |
| `No such module 'Klaritics'` | The **Klaritics** library wasn't added to your app target. Re-check the last step of [Add the package](#add-the-package). |
