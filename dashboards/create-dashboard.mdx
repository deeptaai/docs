Creating a dashboard assembles the charts that matter into a single view.

---

## Who can create one

Only a user with **Full Access** for dashboards can create a dashboard.

| Dashboard project permission | Can create |
| :-- | :--: |
| Full Access | ✓ |
| Editor | ✗ |
| Viewer | ✗ |

Editor works with existing dashboards that have been shared with them, rather than creating new ones.

---

## What happens on creation

<Steps>
  <Step title="The dashboard is created Private">
    A newly created dashboard is **Private** by default. Only you can see it until you share it.
  </Step>
  <Step title="You are assigned ownership">
    The creator becomes the owner, which is what allows duplication and deletion later.
  </Step>
  <Step title="Add charts">
    Pin existing charts you have access to. You can only add charts you are allowed to access.
  </Step>
  <Step title="Share it">
    Move the dashboard to Restricted or Project-wide when it is ready for others. See [Sharing](/dashboards/sharing).
  </Step>
</Steps>

---

## Adding charts

There are two routes onto a dashboard:

<CardGroup cols={2}>
  <Card title="Pin from an analysis" icon="thumbtack" href="/charts/pin-to-dashboard">
    Configure an analysis, then pin its visualization to Overview, an existing dashboard, or a new one.
  </Card>

  <Card title="Save a template" icon="layer-group" href="/templates/overview">
    Configure a template and use **Save as Dashboard**. The result lands in Saved Dashboards.
  </Card>
</CardGroup>

<Note>
  The same chart can be pinned to more than one dashboard. This is useful when a single metric matters across different team views.
</Note>
