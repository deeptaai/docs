A **dashboard** is a collection of charts you have pinned from your analyses. It gives your team a single screen to monitor product health, track experiments, and share insights.

**Saved Dashboards** is the listing of every dashboard you are allowed to access in a project.

## Saved Dashboards and Overview are different

Klaritics has two places a chart can live, and they behave differently.

| | Saved Dashboards | Overview |
| :-- | :-- | :-- |
| **Scope** | A dashboard you create and share | A common project-level page |
| **Who sees it** | Owner and whoever it is shared with | All project users |
| **Card visibility** | Follows dashboard permissions | Visible to everyone |
| **Chart interaction** | Follows chart permissions | Follows chart permissions |

On Overview, every project user sees the chart **card**, even with no access to the chart itself. Opening and editing are still permission-controlled, and chart data is never exposed to someone without access. See [Pin a chart to a dashboard](/charts/pin-to-dashboard).

---

## Dashboards are independent of charts

A dashboard holds references to charts; it does not own them. Permissions for the two are evaluated separately, in both directions.

<Warning>
  Access to a dashboard does **not** grant access to the charts on it. A user who can edit a dashboard may still be unable to open a chart pinned to it.
</Warning>

Deleting a dashboard does not delete its charts. They remain in [Saved Charts](/charts/overview).

---

## What the listing shows

The listing displays only the dashboards you are allowed to access, based on each dashboard's visibility.

| Visibility | Who sees the dashboard |
| :-- | :-- |
| **Private** | Owner only |
| **Restricted** | Owner and explicitly shared users |
| **Project-wide** | Project users, subject to their dashboard project-level permission |
