Cohorts in Klaritics are groups of users who share a behavior, property, or time-based characteristic. You can build cohorts from events, user attributes, or a combination of both, then use them to filter or break down other analyses such as funnels, retention, and chart analysis.

## When to use Cohorts

Use Cohorts when you want to:

- Track users who performed a specific action in a time window
- Compare behavior across user segments in other analyses
- Import user lists from external tools for unified analysis

## Build a cohort

<Steps>
  <Step title="Define the criteria">
    Choose whether the cohort is based on a user property, an event, or a sequence of events within a date range.
  </Step>
  <Step title="Set conditions">
    Add filters such as event count thresholds, property values, or time windows. For example, users who completed at least two purchases in the last thirty days.
  </Step>
  <Step title="Preview and save">
    Review the matching user count, then save the cohort. Saved cohorts are available across all analyses in your project.
  </Step>
  <Step title="Use in analyses">
    Reference the saved cohort as a filter or breakdown in funnels, retention, chart analysis, and more.
  </Step>
</Steps>

## Import external cohorts

Klaritics supports importing cohorts from external systems so you can combine third-party segmentation with your event data. To set this up, see [Third Party Cohorts](/integrations/third-party-cohorts).

## Save and share

Cohort definitions can be pinned to dashboards as widgets so your team can monitor group size and composition over time. You can also configure alerts on a cohort widget to be notified when membership crosses a threshold.
