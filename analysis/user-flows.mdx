User Flows in Klaritics shows the sequence of events users follow after a chosen starting point. Instead of defining a fixed funnel, you explore the actual paths users take through your product. This helps you discover common journeys, unexpected loops, and branches you may not have anticipated.

## When to use User Flows

Use User Flows when you want to:

- Explore how users navigate after landing on a key page or feature
- Discover alternate paths that lead to conversion
- Find unexpected drop-off or backtracking behavior

## Build a user flow

<Steps>
  <Step title="Choose the starting event">
    Select the event that begins the flow, such as app open, homepage view, or feature launch.
  </Step>
  <Step title="Set the depth">
    Choose how many steps forward to visualize. Deeper flows reveal more detail but can add noise.
  </Step>
  <Step title="Apply filters">
    Narrow the flow to a specific audience, platform, or time range to keep the visualization focused.
  </Step>
  <Step title="Explore branches">
    Review the flow diagram to see which events are most common at each step. Click any node to see the subset of users who took that path.
  </Step>
</Steps>

## Save and share

Save the flow configuration so you can revisit it later. Pin it to a dashboard as a widget so your team can monitor how user navigation changes over time. You can also set alerts on the widget to be notified when traffic through a key branch shifts significantly.

<Tip>
  After identifying a promising path in User Flows, define it as a formal [Funnel](/analysis/funnels) to track conversion precisely.
</Tip>
