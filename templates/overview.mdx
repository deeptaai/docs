Dashboard Templates let you get started with analytics without building dashboards from scratch. Each template is a pre-configured, use-case-driven dashboard: you select it, supply the events it needs, and the charts populate immediately.

The flow is the same for every template:

<Steps>
  <Step title="Open Dashboard Templates">
    Use the Dashboard Templates dropdown to reach the templates page.
  </Step>
  <Step title="Pick a template">
    Each card shows the template name, a thumbnail preview, and a short description. Clicking a card opens its landing page.
  </Step>
  <Step title="Configure the inputs">
    Select the events the template needs, and apply any filters.
  </Step>
  <Step title="Review the charts">
    Charts update in real time as you change inputs.
  </Step>
  <Step title="Save as Dashboard">
    The saved dashboard appears in [Saved Dashboards](/dashboards/overview).
  </Step>
</Steps>

## How every template page is built

All templates share the same anatomy.

### Header

Shows the template name and the **Save as Dashboard** call to action.

### Configuration panel

Holds the template's event inputs and filters, which accept user properties and event properties. Inputs are fully editable, and changes trigger real-time updates in the charts.

### Visualization area

The date range defaults to **Last 30 Days** and applies to all charts.

Charts render once the required events are selected. If no events are selected, all charts remain disabled and display:

```text
Select events to generate insights
```

---

## Data states

| State | Behavior |
| :-- | :-- |
| **No events selected** | All charts are disabled |
| **Data available** | Charts render with insights and tooltips |
| **No data available** | `No data available for selected inputs. Try adjusting filters or date range.` |
| **Partial data** | Some charts render; others display `Not enough data to display this chart` |

---

## Saving a template as a dashboard

Clicking **Save as Dashboard** opens a save popup. Once saved, the dashboard is stored in the Saved Dashboards section.

<Warning>
  Only chart configurations are saved. The configuration panel's event selection inputs are **not** persisted, and unsaved changes are not retained.
</Warning>

You must save the dashboard before editing its charts. After saving, you can update the existing dashboard or save it as a new one.
