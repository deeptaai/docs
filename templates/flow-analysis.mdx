The Flow Analysis template gives you a ready-made view of how users move through your product. Instead of building [User Flows](/analysis/user-flows) charts manually, this template sets up the most common journey patterns so you can start analyzing navigation behavior right away.

## What is included

This template creates a dashboard focused on path analysis:

- **Entry and exit flows** showing where users start and where they drop off.
- **Key journey steps** for common paths like onboarding, checkout, or activation.
- **Drop-off points** highlighted so you can identify friction in the experience.

## Customizing the template

The template creates a starting dashboard. You can replace the default goal events with your own, adjust the number of steps shown in each flow, and add complementary widgets such as [Funnels](/analysis/funnels) or [Retention](/analysis/retention) to deepen the analysis.
