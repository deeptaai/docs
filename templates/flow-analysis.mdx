The Flow Analysis template helps you analyze user journeys, conversion behavior, and drop-offs across multiple steps.

With it you can select and order multiple events, apply filters, view conversion and behavioral insights, and save the dashboard for future use.

---

## Configuration panel

| Input | Description |
| :-- | :-- |
| **Multi-step event selection** | Select the events that make up the journey |
| **Step ordering** | Drag and drop, or use sequence selection, to order the steps |
| **Filters** | User properties and event properties |

Inputs are fully editable, changes trigger real-time updates in the charts, and step reordering is supported dynamically.

---

## Charts

Clicking a chart title opens the corresponding analysis, pre-filled with your selected events and a Last 30 Days date range.

### Funnel Conversion Chart

Displays step-wise conversion rates, drop-offs, converted users, and drop-off counts.

- **Label:** Conversion Rate *(top-right)*
- **Title:** "What is the conversion rate of this funnel?"
- **Opens:** [Funnels](/analysis/funnels) with measure **Conversion Rate**
