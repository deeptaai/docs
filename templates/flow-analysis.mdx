The Flow Analysis template helps you analyze user journeys, conversion behavior, and drop-offs across multiple steps.

With it you can select and order multiple events, apply filters, view conversion and behavioral insights, and save the dashboard for future use.

---

## Configuration panel

| Input | Description |
| :-- | :-- |
| **Multi-step event selection** | Select the events that make up the journey |
| **Step ordering** | Drag and drop, or use sequence selection, to order the steps |
| **Filters** | User properties and event properties |

Inputs are fully editable, changes trigger real-time updates in the charts, and step reordering is supported dynamically.

---

## Charts

The dashboard includes five charts. Clicking a chart title opens the corresponding analysis, pre-filled with your selected events and a Last 30 Days date range.

### Funnel Conversion Chart

Displays step-wise conversion rates, drop-offs, converted users, and drop-off counts.

- **Label:** Conversion Rate *(top-right)*
- **Title:** "What is the conversion rate of this funnel?"
- **Opens:** [Funnels](/analysis/funnels) with measure **Conversion Rate**

### Conversion Over Time

Displays how the conversion rate changes over time.

- **Label:** Conversion Over Time
- **Title:** "How is the conversion rate changing over time?"
- **Opens:** [Funnels](/analysis/funnels) with measure **Conversion Over Time**

### Time to Convert

Displays the time taken for users to convert.

- **Label:** Time to Convert
- **Title:** "How long does it take users to convert?"
- **Opens:** [Funnels](/analysis/funnels) with measure **Time to Convert**

### Frequency

Displays how many times users perform the starting event before converting.

- **Label:** Frequency
- **Title:** "How many times do users perform the starting event before converting?"
- **Opens:** [Funnels](/analysis/funnels) with measure **Frequency**

### User Paths

Displays the sequence of actions users take before reaching the final event. It highlights the most common user paths and shows alternative journeys.

When no path data exists:

```text
No path data available. Try selecting events or adjusting filters.
```
