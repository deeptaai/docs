The Feature Adoption template measures how effectively users discover, engage with, and are retained by a specific product feature.

With it you can select a Feature Discovery Event, apply filters, analyze engagement and retention insights, and save the dashboard for future use.

---

## Configuration panel

| Input | Description |
| :-- | :-- |
| **Feature Discovery Event** | Mandatory, single-select |
| **Filters** | User properties and event properties |

Inputs are fully editable, and changes trigger real-time updates in the charts.

---

## Section 1 — User engagement

These charts answer: *"Are users finding and using the feature?"*

### Daily Feature Discovery

**"How many users find my feature each day?"**

Shows how many unique users discover the feature daily.

| Setting | Value |
| :-- | :-- |
| Measure | Unique Users |
| Event | Feature Discovery Event |
| Interval | Daily |
| Date range | Last 30 Days |

Opens a **Line Chart** analysis with the Unique Users measure and your selected event.

### Feature Usage Frequency

**"How often do users get value from your feature?"**

Shows how frequently users interact with the feature.

| Setting | Value |
| :-- | :-- |
| Measure | Frequency Distribution |
| Event | Feature Discovery Event |

Opens a **Bar Chart** analysis with the Frequency Distribution measure.

### Platform Distribution

**"Which platforms do users experience my feature on?"**

Identifies which platforms drive feature usage.

| Setting | Value |
| :-- | :-- |
| Measure | Unique Users |
| Breakdown | Platform |
| Event | Feature Discovery Event |

Opens a **Pie Chart** analysis with the Platform breakdown.

---

## Section 2 — User retention

These charts answer: *"Does the feature bring users back?"*

### Retention After Feature Use

**"How many users return after getting value?"**

Measures whether users continue engaging after using the feature.

| Setting | Value |
| :-- | :-- |
| Event 1 | Feature Discovery Event |
| Event 2 | Any Active Event, or a configurable activity event |
| Measure | Retention Rate |
| Mode | Day-wise retention |
| Date range | Last 30 Days |

Opens a [Retention](/analysis/retention) analysis with the events and configuration pre-filled.

### Average Feature Usage per User

**"How many times does a user explore my feature on average?"**

Shows how deeply users engage with the feature over time.

| Setting | Value |
| :-- | :-- |
| Measure | Average Frequency per User |
| Event | Feature Discovery Event |
| Interval | Time-based |

Opens a **Line Chart** analysis with the Average Frequency measure.
