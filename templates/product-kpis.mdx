The Product KPIs template is the default landing dashboard for the analytics platform. It provides a high-level overview of product health, growth, activation, retention, and engagement in a configurable, interactive format.

It is designed for product managers, growth teams, founders, analysts, and marketers who need a quick read on:

- Product growth trends
- User engagement
- Retention health
- Activation performance
- Conversion effectiveness

The dashboard acts as a starter template and updates dynamically based on the selected events, date ranges, and filters.

---

## Configuration panel

| Input | Description |
| :-- | :-- |
| **Any Active Event** | Mandatory, single-select |
| **Filters** | User properties and event properties |

Inputs are fully editable, and changes trigger real-time updates in the charts.

---

## Charts

Clicking a chart title opens the corresponding creation page, pre-filled with your selected event and a Last 30 Days date range.

### DAU Chart

Displays the number of Daily Active Users on each day.

- **Label:** Uniques *(top-right)*
- **Title:** "Daily Active Users (DAU): How many users are engaging daily?"
- **Opens:** Line Chart creation with measure **Uniques**

### Device Type Chart

Displays the number of users coming from which devices.

- **Label:** Uniques
- **Title:** "Device Type: What devices are your new users on?"
- **Opens:** Pie Chart creation with measure **Uniques**, breakdown **Device Type**

### Frequency Chart

Displays the number of times the user did the event.

- **Label:** Uniques
- **Title:** "Engagement: How often are users performing your event?"
- **Opens:** Bar Chart creation with measure **Uniques**

### Country Chart

Displays the number of users in each country.

- **Label:** Uniques
- **Title:** "User Traffic: Where are users from?"
- **Opens:** Pie Chart creation with measure **Uniques**, breakdown **Country**

### New Users Conversion

Displays the number of new users who did the selected event.

- **Label:** Conversion Rate
- **Title:** "Funnel Conversion: How many users are converting to an end event?"
- **Opens:** [Funnels](/analysis/funnels) creation with New Users as Event A and your selected event as Event B, measure **Conversion Rate**

### New Users Retention

Displays the number of new users retained by performing the selected event.

- **Label:** Retention
- **Title:** "N-Week Retention: What percentage of my users are coming back after N weeks?"
- **Opens:** [Retention](/analysis/retention) creation with New Users as Event A and your selected event as Event B, measure **Retention**
