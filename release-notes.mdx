<Update label="v1.0.0" description="Initial release">
  Klaritics v1.0.0 is the first general availability release of the self-hosted product analytics platform.

  **Included modules**

  - Settings: Roles, Users, Alerts, Integrations
  - Analysis: Chart Analysis, Funnels, Retention, Stickiness, Cohorts, Pivot Tables, User Sessions, Engagement Matrix, Impact Analysis
  - Product Analytics: Product Overview, Onboarding, Feature Engagement, Retention dashboards
  - Dashboards: Saved Dashboards built from pinned charts
  - Charts: Saved Charts with project-level and resource-level permissions
  - Data: Event Taxonomy, Real-time Events, User Profiles
  - Templates: Flow Analysis, Feature Adoption, Product KPIs, User Activity
  - Integrations: Third Party Cohorts
  - Alerts on charts
  - Self-hosted deployment of the entire platform

  **SDKs**

  Klaritics SDKs are available for Web, Android, iOS, React Native, and Flutter with consistent client-facing naming and function signatures. See the [SDK integration guide](/sdk/overview) for details.

  **Not included in v1.0.0**

  The following modules are on the roadmap and are not part of v1.0.0:

  - Compass
  - Session Engagement
  - User Flows
  - Session Replays
</Update>
